# 🌦️ Atmos — Weather Dashboard

A modern, responsive weather dashboard that provides real-time weather conditions and a 5-day forecast for cities around the world.

## 🚀 Live Demo

**[View Atmos Weather Dashboard](https://arhamkhancr608-rgb.github.io/weather-dashboard/)**

## ✨ Features

* 🌍 Search weather for cities worldwide
* 🌡️ Live temperature and feels-like temperature
* 💧 Humidity and wind speed information
* 🌧️ Current precipitation data
* 📅 Five-day weather forecast
* 🌤️ Dynamic weather icons
* 📱 Responsive design for mobile and desktop
* ⚡ Quick search for popular cities
* 🛡️ Error handling for invalid city searches

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Open-Meteo Weather API
* GitHub Pages

## 📸 Preview

Open the [live demo](https://arhamkhancr608-rgb.github.io/weather-dashboard/) to explore the application.

## ⚙️ Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Search for any city to view its weather.

An internet connection is required to retrieve live weather data.

## 🌐 Data Source

Weather information is provided by [Open-Meteo](https://open-meteo.com/).
